# AERION — HVAC & AC Repair Website Template

A complete, responsive single-page website template for air-conditioning, heating, and climate-comfort companies. AERION is built as a trustworthy, locally-focused one-page site that turns a visitor with a broken unit into a booked service call.

Whether you run an HVAC business, an AC repair service, a plumbing and heating company, or any local home-services trade, this template gives you a polished, production-ready starting point — no frameworks, no build step, just clean HTML, CSS, and JavaScript you can host anywhere.

## What's inside

- **A complete single page** with anchored navigation (home, services, why-us, process, installs, contact) that keeps the whole pitch in one scroll.
- **Climate-comfort design system** with a glacier-cyan (cooling) and warm-orange (heating) dual accent, Sora display type, and DM Sans body text.
- **Token-driven CSS** (CSS custom properties) so rebranding is a matter of changing a handful of color and font variables.
- **Vanilla JavaScript interactions** — scroll-reveal animations, count-up statistics, mobile navigation, smooth in-page anchors, and a validated contact form. No dependencies.
- **Fully responsive** layout that adapts from phone to wide desktop.
- **Accessible markup** with semantic HTML, ARIA labels, and `prefers-reduced-motion` support.
- **SEO-ready** meta title, description, and structured content.

## Tech stack

- Pure **HTML5 + CSS3 + vanilla JavaScript**. No Bootstrap, Tailwind, React, or any other framework.
- No bundler, no npm install, no compile step — open the file or drop it on any static host.
- Organized assets: `assets/css/base.css` (design tokens + components) and `assets/js/main.js` (interactions).

## Getting started

1. Download or clone the folder.
2. Open `index.html` in a browser, or deploy the whole folder to Netlify, Vercel, GitHub Pages, or any web server.
3. Replace the placeholder `picsum.photos` images with your own team and job photos.
4. Edit the text, service areas, and tokens to match your business.

## Customization

- **Colors & fonts:** edit the `:root` variables at the top of `assets/css/base.css`.
- **Statistics:** use `data-count="24"` and optional `data-suffix="/7"` on any number element.
- **Logo:** swap the inline SVG inside the `.brand` block in the header and footer.
- **Anchors:** the top nav links to in-page sections — update section `id`s and the matching `href="#..."` together.
